# Telegram Video Downloader Bot

Бот для скачивания видео из YouTube, VK, Pinterest и других сервисов.
Работает на базе aiogram 3 и yt-dlp.

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Установить переменную окружения `BOT_TOKEN`.
3. Запустить `python bot.py`.
